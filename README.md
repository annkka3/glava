# Глава

Личное приложение для чтения: списки книг и подборки, читалка для EPUB и FB2, чтение вслух, учёт страниц и времени, цели и медали.

- Ставится на экран «Домой» на iPhone, работает и на iPad с Mac.
- Открывается без интернета: всё нужное лежит в самом приложении и сохраняется в памяти устройства.
- Хостинг на GitHub Pages, синхронизация через Firebase (тот же проект и аккаунт, что у «Ритма»).
- Не зависит от сторонних сервисов: движок чтения, голоса и шрифты лежат в этом репозитории.

## Как устроено

| Где | Что |
|---|---|
| `index.html`, `css/app.css` | оболочка и оформление («Тиснение»: тёмная и светлая темы) |
| `js/app.js` | запуск, переход между разделами, обработка нажатий |
| `js/store.js`, `js/db.js` | данные: в памяти, в IndexedDB на устройстве; `js/sync.js` отправляет изменения в Firestore |
| `js/model.js` | подсчёты: кольца дня, серия дней («глава»), цели, прогресс подборок, медали |
| `js/screens/` | экраны «Сегодня», «Библиотека», «Подборки», «Итоги», карточка книги, настройки |
| `js/reader/` | читалка (`reader.js`), показ по словам (`rsvp.js`, `reading-text.js`, `rsvp-ui.js`), чтение вслух (`speak.js`), разбор сборников (`omnibus.js`) |
| `js/cards.js` | картинки для отправки: цитата, итоги месяца и года |
| `tts/` | озвучка: разбор текста на фразы, синтез в фоновом потоке, плеер, вопросительный тон (`prosody.js`) |
| `voices/` | русские голоса Piper: Ирина, Дмитрий, Руслан |
| `vendor/` | сторонние компоненты, см. `vendor/README.md` |
| `voice-test/` | отдельная страница проверки голоса |
| `sw.js` | сервис-воркер: кэш файлов для работы без сети (создаётся командой `npm run sw`) |

Данные в Firestore лежат рядом с данными «Ритма»: `users/<uid>/g_books`, `g_cols`, `g_days`, `g_quotes`, `g_meta`. У каждой записи есть время изменения `u`; при расхождении побеждает более новая. Файлы книг в облако не отправляются.

## Страницы и время

Страница электронной книги условная: 1800 знаков, примерно как бумажная. Читалка засчитывает страницы по мере продвижения вперёд (скачок через оглавление чтением не считается), минуты идут, пока книга открыта и листается или пока звучит голос. Бумажные книги отмечаются вручную.

## Чтение по словам

Книга всегда открывается обычной страницей. Кнопка **«По словам»** в шапке включает последовательный показ слов текущей книги. Можно также выделить слово на странице и выбрать **«Читать по словам отсюда»**. Режим готовится на паузе; для запуска нажми **«Начать»**.

- Базовая скорость — от 100 до 600 слов в минуту, начальное значение 200; менять её можно ползунком или кнопками ±10 прямо во время чтения.
- Опорная буква остаётся на одной вертикальной линии. В настройках можно независимо отключить её красную подсветку, паузы на знаках препинания и дополнительное время длинных слов.
- На паузе виден контекст текущего предложения. Есть возврат на 10 слов, к началу предложения и кнопка **«Обычная страница»**.
- Точное место сохраняется при паузе, выходе и периодически во время чтения. На обычной странице последнее слово ненадолго подсвечивается. После закрытия и повторного открытия книги режим можно включить с этого же слова.
- При уходе в фон, закрытии книги или открытии диалога поток останавливается; возврат в приложение сам его не запускает.
- Минуты учитываются по времени активного показа. Страницы добавляются по реально показанному тексту за достигнутой границей чтения; перемотка и повторный показ уже зачтённых слов не добавляют страницы.

Паузы увеличивают длительность показа, поэтому фактический темп может быть ниже базового. Показ поддерживается для текстовых EPUB и FB2; разделы с таблицами, формулами или сложной вёрсткой предлагают продолжить обычной страницей. После загрузки обновления режим работает без сети с книгами, сохранёнными на устройстве.

Клавиатура: пробел — старт/пауза, стрелка влево — назад на 10 слов, Home — к началу предложения, ± — скорость, Escape — обычная страница. Поля и кнопки сохраняют стандартное управление с клавиатуры.

## Сборники

Если в файле несколько произведений (собрание сочинений, том рассказов), приложение читает его оглавление и ищет в библиотеке записи с такими же названиями того же автора. Найденные произведения получают ссылку на своё место в файле: открываются из своей карточки сразу на нужной странице, ведут свой счёт страниц и сами отмечаются прочитанными, когда чтение доходит до следующего произведения. Поиск запускается при добавлении файла и кнопкой «Найти в файле отдельные произведения» в карточке книги.

## Озвучка

Текст главы режется на фразы, каждая превращается в фонемы (espeak-ng), а затем в звук (голос Piper через ONNX Runtime). Всё происходит на устройстве. Звук идёт через обычный аудиоплеер страницы, поэтому им можно управлять с экрана блокировки и с наушников. Голос (63 МБ) и движок (32 МБ) скачиваются один раз и остаются в памяти устройства.

Ирина и Дмитрий читают вопросы ровным тоном, поэтому у вопросов без вопросительного слова приложение после синтеза поднимает тон последнего слога (`tts/prosody.js`; сила настраивается, можно выключить). Руслан задаёт вопросы сам.

## Разработка

```bash
npm install
```

```bash
npm run serve
```

Открой http://localhost:8767.

`npm test` проверяет разбор текста, интервалы, паузы и точность учёта чтения. Браузерные сценарии запускаются через `npm run test:browser`; установка браузеров и подробности описаны в [tests/browser/README.md](tests/browser/README.md). GitHub Actions запускает их в Chromium и WebKit на ветках `feat/**`, в PR и в `main`.

Перед публикацией обнови список файлов и версию кэша, иначе телефоны продолжат показывать старую версию:

```bash
npm run sw
```

`npm run vendor` пересобирает Firebase SDK (нужны пакеты `firebase` и `esbuild`), `npm run icons` перерисовывает иконки.

Личные данные (списки книг, отметки о прочитанном) лежат в папке `private/` и в репозиторий не попадают. Первый раз они загружаются в приложение через «Настройки → Загрузить из файла».

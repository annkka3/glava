# Глава

Личное приложение для чтения: список книг, читалка для EPUB и FB2, учёт страниц и времени, цели и медали, чтение вслух.

- Ставится на экран «Домой» на iPhone, работает и на iPad с Mac.
- Открывается без интернета: всё нужное лежит в самом приложении и сохраняется в памяти устройства.
- Хостинг на GitHub Pages, синхронизация через Firebase (тот же проект, что у «Ритма»).
- Не зависит от сторонних сервисов: движок чтения, голоса и шрифты лежат в этом репозитории.

## Что уже есть

| Папка | Что в ней |
|---|---|
| `voice-test/` | страница проверки голоса: послушать голоса и проверить чтение с выключенным экраном |
| `tts/` | озвучка: разбор текста на фразы (`text.js`), синтез в фоне (`worker.js`), плеер (`player.js`) |
| `voices/` | русские голоса Piper: Ирина и Дмитрий |
| `vendor/` | сторонние компоненты, см. `vendor/README.md` |
| `fonts/` | шрифты Cormorant и Onest |

Читалка, библиотека, цели и статистика появятся следующими.

## Как устроена озвучка

Текст режется на фразы, каждая фраза превращается в фонемы (espeak-ng), а затем в звук (голос Piper через ONNX Runtime). Всё это происходит на устройстве. Звук идёт через обычный аудиоплеер страницы, поэтому им можно управлять с экрана блокировки и с наушников.

Голос (63 МБ) и движок (32 МБ) скачиваются один раз при первом включении и остаются в памяти устройства.

## Разработка

```bash
npm install
```

```bash
npm run serve
```

Открой http://localhost:8767.

Личные данные (списки книг, отметки о прочитанном) лежат в папке `private/` и в репозиторий не попадают.

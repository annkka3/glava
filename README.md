# Глава

Личное приложение для чтения: списки книг и подборки, читалка для EPUB и FB2, чтение вслух, учёт страниц и времени, цели и медали.

- Ставится на экран «Домой» на iPhone, работает и на iPad с Mac.
- Открывается без интернета: всё нужное лежит в самом приложении и сохраняется в памяти устройства.
- Хостинг на GitHub Pages, синхронизация через Firebase (тот же проект и аккаунт, что у «Ритма»).
- Не зависит от сторонних сервисов: движок чтения, голоса и шрифты лежат в этом репозитории.

## Как устроено

| Где | Что |
|---|---|
| `index.html`, `css/app.css` | оболочка и оформление («Тиснение»: тёмная и светлая темы) |
| `js/app.js` | запуск, переход между разделами, обработка нажатий |
| `js/store.js`, `js/db.js` | данные: в памяти, в IndexedDB на устройстве; `js/sync.js` отправляет изменения в Firestore |
| `js/model.js` | подсчёты: кольца дня, серия дней («глава»), цели, прогресс подборок, медали |
| `js/screens/` | экраны «Сегодня», «Библиотека», «Подборки», «Итоги», карточка книги, настройки |
| `js/reader/` | читалка (`reader.js`) и чтение книги вслух (`speak.js`) |
| `tts/` | озвучка: разбор текста на фразы, синтез в фоновом потоке, плеер |
| `voices/` | русские голоса Piper: Ирина и Дмитрий |
| `vendor/` | сторонние компоненты, см. `vendor/README.md` |
| `voice-test/` | отдельная страница проверки голоса |
| `sw.js` | сервис-воркер: кэш файлов для работы без сети (создаётся командой `npm run sw`) |

Данные в Firestore лежат рядом с данными «Ритма»: `users/<uid>/g_books`, `g_cols`, `g_days`, `g_quotes`, `g_meta`. У каждой записи есть время изменения `u`; при расхождении побеждает более новая. Файлы книг в облако не отправляются.

## Страницы и время

Страница электронной книги условная: 1800 знаков, примерно как бумажная. Читалка засчитывает страницы по мере продвижения вперёд (скачок через оглавление чтением не считается), минуты идут, пока книга открыта и листается или пока звучит голос. Бумажные книги отмечаются вручную.

## Озвучка

Текст главы режется на фразы, каждая превращается в фонемы (espeak-ng), а затем в звук (голос Piper через ONNX Runtime). Всё происходит на устройстве. Звук идёт через обычный аудиоплеер страницы, поэтому им можно управлять с экрана блокировки и с наушников. Голос (63 МБ) и движок (32 МБ) скачиваются один раз и остаются в памяти устройства.

## Разработка

```bash
npm install
```

```bash
npm run serve
```

Открой http://localhost:8767.

Перед публикацией обнови список файлов и версию кэша, иначе телефоны продолжат показывать старую версию:

```bash
npm run sw
```

`npm run vendor` пересобирает Firebase SDK (нужны пакеты `firebase` и `esbuild`), `npm run icons` перерисовывает иконки.

Личные данные (списки книг, отметки о прочитанном) лежат в папке `private/` и в репозиторий не попадают. Первый раз они загружаются в приложение через «Настройки → Загрузить из файла».
